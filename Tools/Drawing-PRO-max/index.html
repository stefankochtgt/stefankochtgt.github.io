Drawing PRO max — keyboard and mouse

Free drawings like Visio: shapes, text, connectors glued to shapes, text formatting and shape styles, several pages. Everything is stored in this browser only.

Drawing
Rectangle / ellipse / line (Tools)drag on the page; a click gives the default size; Shift: square / circle / straight line
Textclick or drag on the page, type, click elsewhere (or Esc, Ctrl+Enter) to finish
Connectordrag from a shape onto another: the ends are glued (green handles) and follow the shapes. Dropped on a shape's line, the end sits on that line, snapped to the raster shown as dots (twelfths of each side: halves, thirds, quarters — equal distances are easy); on an own × point it stays there; dropped inside the shape it takes the nearest side. Right angles (routed around the two shapes) or straight (Line menu)
Connection point (×)click on a shape to add a point where connectors can glue; click an own point to remove it
Editing
Click / Shift or Ctrl + click / drag on the empty pageselect one / more / all inside the frame
Drag / handles / arrow keysmove / resize (Shift: keep the proportions) / nudge 1 px (Shift: 10)
Double-click, F2, or just typeedit the shape's text (typing replaces it)
Font, Paragraph, Shape stylesapply to the selected shapes (the whole text of a shape)
Ctrl+C / X / V / D, Delcopy / cut / paste / duplicate, delete
Ctrl+Z / Ctrl+Yundo / redo
Right-clickedit text, cut / copy / paste, front / back, link, delete
Viewing and pages
Ctrl + wheel / wheel / middle button or Space + dragzoom / scroll / move the view; Fit shows the page
Page tabs (below)switch; + new page; double-click renames; File: duplicate, delete
Export PNG / SVG / XML, Import XMLthe page as an image; all pages as XML (the workbench and the standalone Drawing PRO max read each other's files)
Your drawings are stored in this browser (nothing is uploaded) — Import / Export > Export XML keeps a copy or moves them to another computer. © TEGRITY · tegrity.eu ·
