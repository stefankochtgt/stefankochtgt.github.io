Manual FTA

Fault trees drawn by hand. Add top event starts a tree. Add gate / Add basic event, then click gates: each click adds a gate or basic event below the clicked gate, with a default ID (TP-1 for a top event, GT-1 for a gate, EV-1 for a basic event, numbered on and never reused) and no title yet; the mode stays on until Esc or the button again. Click an element afterwards to enter its title, description, its ID (any unique ID you like) and an optional label, which is shown next to its box. A gate with two or more inputs shows its OR / AND symbol, a gate with one input is drawn as an intermediate event, a gate with nothing below it yet as a triangle, a basic event is a circle and cannot have anything below it. Right-click an event for the same and more: edit, AND / OR, move left / right, delete. Hold Ctrl and drag an event onto a gate or top event to move it there with everything below it. In the dialog, Enter saves (Shift+Enter for a new line), Esc cancels.
Your trees stay in this browser only (nothing is sent anywhere). Use Export to save them as a file (manual_fta.xml, the same format as the TEGRITY Safety Model) and Import to load one.
