Functional Chain PRO max — keyboard and mouse

Functional chains drawn by hand: a function with sub-functions is a box around them, ordered left to right by their flows; functions of one system are framed by a red dashed border. File holds several diagrams. Everything is stored in this browser only.

Building
+ Function / N / right-click the empty areaa new function (ID, title, the function it is inside, its system)
Right-click a functionedit, add a sub-function (inside it), add the next function with a flow to it, move out of its box, delete
Double-click a function, F2edit: ID, title, Inside (the function it belongs to — makes it a sub-function), System (functions of one system next to each other share one red border) — Enter saves, Esc cancels
Hold Ctrl + drag from one function onto anothera flow “this feeds into that” — the drag direction is the flow direction
Drag a function or a boxmoves it (a box with everything in it); the place is kept
Automatic layoutplaces all functions again like the Functional Chain view: left to right in flow order, sub-functions one row lower
Click, Ctrl + clickselect one / more functions or flows; Del deletes them (a function with what is inside it), Esc clears
Right-click a flow / a red borderdelete the flow / remove the system from those functions
Ctrl+Z / Ctrl+Yundo / redo
Viewing
Hold Shift + hover a functionfades everything except that function and its own arrows
Mouse wheel / drag the backgroundzoom / move the view; Fit shows everything
Files
Fileseveral diagrams: new, rename, duplicate, delete; the list in the toolbar switches
Export JPG / PNGthe diagram as an image, everything at high resolution on white
Export XML / Import XML…all diagrams as one file; an import adds its diagrams. The workbench's Manual Functional Chain and the standalone Functional Chain PRO max read each other's files
