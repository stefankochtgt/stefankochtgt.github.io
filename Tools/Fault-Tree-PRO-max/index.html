Fault Tree PRO max — keyboard and mouse

Fault trees drawn by hand. File holds the analyses — separate sets of trees; event IDs (TP-, GT-, EV-) are unique across all of them. Everything is stored in this browser only.

Building
New top event icona new tree — asks: this analysis or a new analysis page
New gate / basic event icon, then click gatesadds one below each gate you click; Esc or the icon again ends
Click an eventselects it (red); a second click on the title (or F2) renames the title in place, a second click on the ID box renames the ID — Enter or a click elsewhere saves, Esc cancels
Double-click an eventedit title, description, ID, label, H category / ASIL — Enter saves, Shift+Enter new line, Esc cancels
Right-click a gate > Continue on a new pageits branch goes onto a page of its own (Page list); on this page a triangle with “…” stands for it — click the triangle to jump to that page; for big trees and PDFs (printed with its page number)
Explorer (left) / Diagram · Gridthe tree on the left lists the analyses and their fault tree pages (a continued page below the page it continues from) — click a page to open it, the boxes open / close a branch, the toolbar icon shows / hides it; Grid: all gates or all basic events as a table with every field — search all columns, filter each column, click a header to sort, double-click a row to show it in the diagram
Compact iconcompact display: the same gates and events, closer together; the ASIL / H square and the label are drawn inside the description box; also for the JPG, LaTeX and PDF export; click again for the normal display
Save (Ctrl+S) / Version controlevery change is kept at once; Save also creates a numbered revision with what changed and when (the button is marked while there are unsaved changes); the Version control tab lists the revisions with their changes — Restore makes one current again (unsaved changes are saved first)
Small triangle on the side / ▲ ▼on its own page the continued gate has a small triangle with “…” — click it to go back to the page it continues from; ▲ next to the Page list: the page above, ▼: the page of the selected transfer triangle, else the first page continued from here
Right-click an eventadd below, edit, AND / OR, make gate / basic event, move left / right, H category / ASIL, colour, delete
Moving and copying
Phone / tablettap = click, long-press = right-click; the event menu has Select and Move / copy to… (then tap the gate); pinch zooms
Ctrl + drag onto a gatemenu: move here, copy (same IDs = the same event, dashed box), copy with new IDs
Change a repeated (dashed) eventasks: change all occurrences, or only this one (it gets a new ID)
Selecting several

Finding and viewing
Find gates / basic events iconby ID, text, H category / ASIL (exact: H3 ≠ H3+) or colour; Enter / Shift+Enter next / previous, Esc closes
Mouse wheel / drag the backgroundzoom / move the view; fit-to-window icon shows everything
